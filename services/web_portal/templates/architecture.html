5-Stage Deterministic Pipeline Topology

[UNIDIRECTIONAL SENSING → BIDIRECTIONAL CONTROL]
STAGE 01 SENSE
Edge Hardware Node
  • MCU: ESP32-S3 (Xtensa LX7)
  • CO2: Sensirion SCD30 (I2C)
  • Temp: Aosong DHT22 (1-Wire)
  • Actuator: 12V 4-Wire PWM Fan
  • Isolation: PC817 Optocoupler
STAGE 02 TRANSPORT
Zero-Trust Network
  • Broker: Mosquitto 2.0.18
  • Port: 8883 (mTLS 1.3)
  • Crypto: ECDSA / P-256
  • Ingress: sdv/vehicle_01/telemetry
  • Egress: sdv/vehicle_01/control/cmd
STAGE 03 STANDARDISE
oneM2M Middleware
  • Entity: ACME IN-CSE
  • Base: /sdv-cse
  • AE: AE_CabinNode_Car01
  • Bridge IPE: Node-RED Ingress
  • Primitive: m2m:cin (JSON:0)
STAGE 04 PERSIST
TSDB & Health Engine
  • Classifier: Bridge AE Service
  • Latency Bound: τ ≤ 2.5s
  • Delta-T Bound: ΔT ≤ 1.5°C
  • TSDB: InfluxDB 2.x
  • Bucket: cabin_telemetry
STAGE 05 ACTUATE
Closed-Loop Control
  • Decision: Grafana / Edge Engine
  • Purge Mode: 75% at CO2 ≥ 800ppm
  • Target Cnt: cnt_actuator_commands
  • Webhook: Node-RED /downlink
  • Egress: MQTT QoS 1 Directive
