Latency Boundary Exceeded
  • Latency (τ): > 2.5s and ≤ 60s
  • Cause: CAN/MQTT buffer delay
  • Impact: Non-blocking advisory
  • Action: InfluxDB tag health_state=STALE
STATE: DEGRADED
Thermal Disparity Divergence
  • Thermal (ΔT): > 1.5°C between sensors
  • Cause: Sensor drift, airflow bias
  • Impact: Warning flag raised
  • Action: InfluxDB tag health_state=DEGRADED
STATE: FAULT
Hardware or Ingestion Fault
  • Trigger: Null readings, τ > 60s
  • Cause: Line detachment, out-of-range
  • Impact: ASIL safety candidate
  • Action: InfluxDB tag health_state=FAULT
